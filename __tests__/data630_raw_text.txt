COURSE CATALOG DESCRIPTION
This graduate-level systems course provides an in-depth study of distributed machine learning pipelines, scalable
model training, inference serving, and enterprise MLOps architectures. Students will implement real-time feature stores,
containerized model deployment with Kubernetes, distributed gradient descent using PyTorch DDP and Ray, and
automated continuous integration/continuous deployment (CI/CD) pipelines for foundation models. 
PROGRAM LEARNING OUTCOMES & TECHNICAL COMPETENCIES
PLO 1 (Distributed Infrastructure): Architect and scale distributed model training clusters across multi-node GPU
instances using PyTorch DDP and Ray Train.
PLO 2 (Production Serving & Low Latency): Deploy high-throughput, sub-100ms model inference endpoints
utilizing Triton Inference Server, vLLM, and Redis cache clusters.
PLO 3 (Continuous Pipeline Orchestration): Implement reproducible CI/CD for machine learning (MLOps) with
automated data drift monitoring and model registry management.
PLO 4 (Ethical AI & Data Governance): Implement audit logging, data lineage tracking, privacy-preserving
machine learning, and cost-optimization governance in cloud environments.

ASSIGNMENT SPECIFICATIONS
1. Distributed Training Benchmark Project (30%)
Students implement and profile data-parallel and pipeline-parallel distributed training routines for a 3-billion-parameter
Transformer architecture using PyTorch DDP and Ray on a multi-GPU cluster. The deliverable includes a reproducible
GitHub repository, distributed GPU utilization flame graphs, scaling efficiency analysis, and an 8-page IEEE-format
technical whitepaper. 
2. Production Inference Microservice & Load Test (25%)
Students containerize a quantized deep learning model and expose low-latency gRPC/REST endpoints using Triton
Inference Server or vLLM. The deliverable requires Locust or k6 load test results demonstrating sustained throughput
under 1,000 concurrent RPS with p99 latency < 85ms, complete with Prometheus/Grafana monitoring configurations. 
3. Automated End-to-End MLOps Pipeline Capstone (30%)
In teams of two, students design a complete cloud-native pipeline: automated feature engineering (Feast), model
tracking and registry (MLflow), scheduled continuous training (Kubeflow/Airflow), automated Canary deployment on
Kubernetes, and drift detection (Evidently AI). Includes live deployment validation and an oral technical pitch. 
4. Architecture Seminar & Code Reviews (15%)
Evaluated through structured peer code reviews in GitHub pull requests, participation in technical whitepaper
discussions, and bi-weekly architecture decision records (ADRs) submitted during lab sessions.
