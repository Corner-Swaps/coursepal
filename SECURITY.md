# Security Policy

## Supported Versions

Security fixes and dependency patches are provided for the active release line:

| Version | Supported          |
| :------ | :----------------- |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security issue or data exposure concern in CoursePal, please disclose it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send full details to:
   - **Email**: [goloubov@gmail.com](mailto:goloubov@gmail.com)
3. Include:
   - Specific component or API endpoint affected
   - Reproduction steps or proof of concept
   - Device and platform details
4. We acknowledge reports within 48 hours and work on remediation with top priority.
